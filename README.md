#Tema css para el frontend de ainvarCMS

Aquí hay 3 ejemplos de temas sencillos para ainvarCMS:

- nature
- tema-horizonte
- tema-medianoche

Estos temas se instalan de la misma maner que los módulos, se sube el archivo zip desde la sección Temas y se pulsa instalar. Después hay que activarlo desde la misma sección.
